# Kanban Task Timer

Kanban Task Timer ajoute des minuteurs persistants et des outils de suivi aux cartes du module Kanban pour Obsidian.

## Fonctionnalités

- Minuteurs avec compte à rebours persistant
- Démarrage, pause et réinitialisation des minuteurs
- Durées agrégées pour les sous-listes liées
- Prévisions de fin et heures de début estimées
- Heures de début imposées et points de contrôle
- Affichage ou masquage des minuteurs par colonne
- Sous-listes liées cliquables
- Suppression de cartes depuis le tableau

## Dépendance

Ce module complète le module communautaire **Kanban**. Installez et activez Kanban avant d’activer Kanban Task Timer.

## Installation

Dans Obsidian, ouvrez **Réglages → Modules complémentaires → Parcourir**, recherchez **Kanban Task Timer**, puis installez et activez le module.

Pour tester une version non publiée, installez le module **BRAT**, puis ajoutez le dépôt GitHub :

`lastseenat/Kanban-Task-Timer`

## Utilisation

Ouvrez un tableau Kanban. Les contrôles de durée apparaissent sur les cartes contenant une durée au format `— 1:30` ou `— 1:30:00`.

Les réglages du module sont enregistrés localement dans `data.json` et ne doivent pas être partagés entre les vaults si vous ne souhaitez pas partager la même configuration.
